# Personal Portfolio Website

## Overview
This is a responsive personal portfolio website developed using HTML, CSS, and JavaScript. It showcases personal information, skills, projects, and contact details in a structured and interactive format.

## Features
- Responsive design for different screen sizes
- Navigation menu with smooth scrolling
- About section with academic and personal details
- Skills section categorized into technical and soft skills
- Projects section with live links and GitHub references
- Contact form integrated with Google Sheets
- Social media links and downloadable resume

## Sections

### Header
- Displays name and introduction
- Navigation bar with links to different sections

### About
- Contains academic background and achievements
- Highlights interests in software development and machine learning

### Skills
- Programming Languages: C++, Python

- Data Science: NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn
- Database: SQL, MySQL
- Core Subjects: DSA, OOP, OS, DBMS
- Soft Skills: Problem-solving, communication, leadership

### Projects

Each project includes a brief description and link to GitHub or live demo.
